# Carify frontend

This React application is documented with the rest of the project in [`../docs/services/frontend.md`](../docs/services/frontend.md).

From this directory, install dependencies and start the development server:

```sh
npm ci
npm start
```

The current API URL is hard-coded in `src/components/Home.js`; see the [frontend guide](../docs/services/frontend.md#current-behavior) before connecting this app to a local backend.
